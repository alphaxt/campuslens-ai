# Examples of user stories:

As a student,
I want to submit a campus issue in natural language,
so that I do not need to know the correct category beforehand.

# Acceptance criteria might be:

WHEN a student submits a valid issue description
THE SYSTEM SHALL analyze the description with AI.

THE SYSTEM SHALL determine:
- category
- severity
- location when possible
- suggested department
- concise issue summary.

# Another:
As an administrator,
I want to view high-priority campus issues,
so that urgent problems can be addressed first.
